# ТренMaxxing — сборка Android-приложения (APK)

Внутри — готовый проект на Capacitor. Само приложение лежит в `www/index.html`, иконки — в `assets/`.

## Способ 1. Без установки Android Studio (GitHub Actions)

1. Создайте репозиторий на github.com и загрузите в него всё содержимое этой папки (вместе с папкой `.github`).
2. Откройте вкладку **Actions → Build APK → Run workflow**.
3. Через 5–10 минут в запуске появится файл **TrenMaxxing-apk**. Скачайте его, внутри `app-debug.apk`.
4. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

## Способ 2. На своём компьютере

Нужны Node.js 18+, JDK 17 и Android SDK (проще всего — установить Android Studio).

    ./build.sh

APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
Чтобы открыть проект в Android Studio: `npx cap add android`, затем `npm run open`.

## Если меняете приложение

Правьте `www/index.html`, затем `npx cap sync android` и пересоберите APK.

## Публикация в Google Play

Debug-APK подходит для установки у себя. Для Google Play нужен подписанный релиз (AAB):
в Android Studio — Build → Generate Signed Bundle / APK. Хранилище ключей сохраните: без него обновления выпустить нельзя.
Смените `appId` в `capacitor.config.json` (сейчас `com.trenmaxxing.app`) до первой сборки, если нужен свой идентификатор.

## Что учесть

- Шрифты (Barlow) подгружаются из интернета; офлайн приложение покажет запасной шрифт. Чтобы встроить их, скачайте файлы шрифтов в `www/` и подключите через `@font-face`.
- Данные (аккаунты, вес, программы) хранятся в самом приложении на телефоне. При удалении приложения они пропадут.
- Запросы к нейросети идут напрямую с телефона к выбранному провайдеру; ключ хранится только на устройстве.
